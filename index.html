Data Engineering, AI a Full-stack Development

Jako Data Engineer navrhuji a orchestruji produkční ETL pipelines, které automatizovaně zpracovávají data z různých zdrojů a ukládají je do lakehouse architektury postavené na DuckDB a MotherDuck. Databázové systémy spravuji v Supabase a Google Cloud Platform. Moje datové pipeline dosahují stoprocentní spolehlivosti a jsou nasazeny pro mezinárodní klienty.

V oblasti umělé inteligence integruji jazykové modely přes Claude API od Anthropic a Anthropic SDK. Vyvíjím AI-powered scoring modely, konverzační rozhraní a inteligentní nástroje, které automatizují business rozhodování a přinášejí měřitelné výsledky.

Jako Full-stack Developer stavím kompletní webové aplikace od Python backendů a REST API po responzivní React frontendy stylované v TailwindCSS. Každý projekt je optimalizovaný pro výkon, SEO a uživatelský zážitek na všech zařízeních včetně mobilních telefonů.

Projekty — AI systémy, data engineering a webové aplikace

Tref Kára — AI car marketplace engine

AI-powered marketplace engine pro automobilový trh v České republice. Systém využívá web scraping pro sběr dat z trhu, která jsou agregována do MotherDuck Lakehouse pomocí DuckDB. Claude API prioritizuje parametry vozidel jako prestiž, TCO a komfort a generuje cenový index elektromobilů versus spalovacích vozidel v reálném čase. Technologie: Python, DuckDB, Claude API, web scraping, lakehouse architektura.

Jak to mají sousedi — B2B market intelligence engine

Produkční systém pro sběr a analýzu dat o cenách služeb a dostupnosti poskytovatelů v B2B sektorech napříč regiony České republiky. Zahrnuje geospatial analýzu podle krajů, automatizované sektorové filtrování a competitive benchmarking pro řemeslníky a firmy. Technologie: Python, SQL, data harvesting, geospatial analýza.

IIIDM — Full-stack aplikace a datové pipelines

Full-stack vývoj datově náročných aplikací pro mezinárodní konzultační firmu IIIDM. Architektura Python backendů s interaktivními React frontendami, orchestrace automatizovaných měsíčních ETL pipeline a správa DuckDB a Supabase databází. Technologie: Python, Supabase, DuckDB, Node.js, React.

Klientské weby — responzivní webové aplikace

Návrh a vývoj moderních responzivních webových aplikací pro malé a střední firmy v Česku. Technická SEO optimalizace, vlastní branding, mobile-first přístup a vysoký výkon na Google PageSpeed. Reference: kurzystudiomirage.cz, kadernicehelena.cz. Technologie: React, TailwindCSS, Node.js, SEO.
